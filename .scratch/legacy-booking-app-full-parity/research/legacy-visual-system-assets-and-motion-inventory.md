# Legacy Booking App visual system, assets, and motion inventory

## Scope and confidence

This is a static-source inventory of `apps/booking-app` plus the visual primitives it directly imports from `packages/view`. **Observed** means present in source. **Inferred** means a migration recommendation or runtime conclusion not proven by screenshots. Generated `dist/` files were excluded. Brand-supplied images/colors are runtime data and therefore cannot be enumerated here.

## Exact theme contract (observed)

- Spacing is a 4 px grid: `space[0..100] = 0..400`, with `space.unit = 4`. Breakpoints are exactly `375px`, `1024px`, `1440px`; font-size tokens are `12, 13, 15, 17, 18, 20, 22, 28, 34, 48`; motion tokens are page `duration=.3s`, page `delay=.3s`, interaction `.15s` ([default theme:6-30](/Users/hassan/Desktop/ssqu/recreate/apps/booking-app/sources/styles/themes/default/index.ts#L6)).

Premium mode also flips cart/breakdown/promo semantics to light surfaces ([branded overrides:3-13](/Users/hassan/Desktop/ssqu/recreate/apps/booking-app/sources/styles/themes/branded/colors.ts#L3)); it is gated by iframe/environment and `hasPremiumBranding` ([BrandedTheme:58-96](/Users/hassan/Desktop/ssqu/recreate/apps/booking-app/sources/contexts/BrandedTheme/BrandedTheme.tsx#L58)).

## Layout and responsive contract (observed)

- `html/body/#root` fill the viewport. At `min-width:376px`, root is centered and capped at **375 px**, making the production widget fundamentally mobile-width even on desktop ([document:3-34](/Users/hassan/Desktop/ssqu/recreate/apps/booking-app/sources/styles/global/document.ts#L3)). All elements inherit border-box/font; focus outlines are globally removed; tap highlight is transparent; role buttons use `touch-action: manipulation` ([document:36-55](/Users/hassan/Desktop/ssqu/recreate/apps/booking-app/sources/styles/global/document.ts#L36)). The missing global focus indicator is an observed accessibility risk, not a contract to reproduce.
- Layout uses `Box`/`Flex` styled-system props throughout and a page/title/content/cart stack. Widget titles are absolutely layered over content and animated; the source comment explicitly coordinates title delay with route `AnimatePresence` ([WidgetContainer styles:85-112](/Users/hassan/Desktop/ssqu/recreate/apps/booking-app/sources/components/molecules/WidgetContainer/styles.ts#L85)).
- The theme exposes tablet/desktop breakpoints, but the root cap means they generally matter only in iframe/alternate containing contexts or legacy remnants. **Inferred:** parity should first target 320–375 CSS px and viewport-height extremes; treat 1024/1440 rules as component-specific evidence, not a new wide layout.

## Actionable StyleX mapping (recommended/inferred)

Create a dedicated `bookingTheme` (do not merge these semantics into the starter’s general theme):

| Legacy                      | StyleX vocabulary                                                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `space[n]`                  | `bookingVars.space0..space100` generated in 4 px increments; primitives accept constrained `gap/padding/margin` tokens                            |
| color object + alpha arrays | named `bookingColors` variables; expand ramps to stable names (`blackA00…A100`, etc.); never index an array at render time                        |
| runtime premium overrides   | a second `stylex.createTheme(bookingVars, values)` selected at the booking boundary; compute sanitized brand palette before render                |
| fontSizes                   | semantic text recipes (`caption`, `footnote`, `body`, `headline`, `title1…largeTitle`, `priceDisplay`) backed by exact sizes/weights/line heights |
| animation numbers           | `motionFast:150ms`, `motionPage:300ms`, `motionPageWithDelay:300ms`; shared Framer recipes own enter/exit behavior                                |
| breakpoints/root cap        | `BookingViewport` owns full-height and centered 375 px max-width; component media queries remain local                                            |
| appLayers                   | `bookingLayers` constants/variables with semantic names, preserving exact ordering                                                                |

Build these primitives first: `BookingViewport`, `Stack`, `Inline`, `Surface`, `Divider`, `Text`, `Icon`, `Avatar`, `Button`, `IconButton`, `Field`, `SelectableCard`, `Skeleton`, `Backdrop`, `Sheet`, `PopupStack`, `Toast`, `Tooltip`, `ProcessingOverlay`, and motion wrappers `FadePresence`, `ScalePresence`, `HeightPresence`, `CalendarPresence`, `RoutePresence`. Each primitive should expose only the observed semantic states above. Keep Framer Motion for layout/exit animations; use StyleX for static/state styling. Add `data-premium`, `data-selected`, `data-expanded`, and `data-status` selectors at primitive boundaries rather than duplicating styled-component conditionals.

Migration acceptance rules: exact computed colors/spacing/type at 375 px; same overlay order and scroll containment; same enter/exit sequencing and durations; SVG snapshots retain geometry/colors; remote brand images preserve crop/fallback; reduced-motion alternative; focus-visible restored without changing pointer visuals; asset-license review completed before redistribution.
