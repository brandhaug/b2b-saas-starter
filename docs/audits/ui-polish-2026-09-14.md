# Web app UI-polish review

Baseline reviewed 2026-09-14 against the UI-polish rules supplied in the request, at commit `17747f9a`. The findings and line numbers below describe that baseline. The follow-up implementation addresses these findings in the same branch; verification is recorded under Remediation below.

12 findings: 10 MEDIUM, 2 LOW, no confirmed HIGH. Approval below applies to the inspected coverage, not to every possible application state. The verification table records the limits.

The review preserves the existing Catppuccin Mocha theme, square panels, control tokens, density, and component library. Typography, accessibility, and layout were not scored under this rubric. Impeccable supplied project context and a mechanical scan; the supplied UI-polish rules determine the findings and verdict.

## Remediation

The follow-up addresses all 12 findings while keeping the existing theme, density, component library, and intentional hero entrance. `DESIGN.md` records the shared interaction rules.

| Finding group                   | Implemented result                                                                                                                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Interruptible state changes     | Accordion height and shared overlay properties use CSS transitions with Base UI lifecycle states. The aligned select remains instant.                                                                                     |
| Exit motion and backdrops       | Overlays enter from 8px and exit toward 4px of fixed vertical displacement with `ease-out`. Backdrops fade without competing keyframes. Dialog centering stays independent of motion.                                     |
| Command palette lifecycle       | The lazy dialog stays available after first use so Base UI can complete dismissal. Its query stays visible during exit and resets on button or keyboard reopening.                                                        |
| Toast dismissal                 | Normal front, expanded, and collapsed-stack dismissals retain their resting offsets and use a 4px displacement with 150ms transform/opacity transitions. Swipe rules remain separate.                                     |
| Contextual icons                | A shared recipe uses scale 0.25/1, opacity 0/1, blur 4px/0px, and `cubic-bezier(0.2, 0, 0, 1)` at 150ms. Icon pairs remain mounted; rotating spinners sit inside the transitioned layer.                                  |
| Concentric radii                | Menus use the existing 8px base token, not `rounded-lg`, which intentionally means square in this project. Their padding and items are 4px. All/Any inner controls use 4px radii inside the 6px wrapper with 2px padding. |
| Press feedback                  | Shared buttons and the hero GitHub CTA press to 0.96. `Button` consumes a `static` opt-out without forwarding it to the DOM.                                                                                              |
| Exact properties                | Overlay transitions name transform/opacity, icon transitions name filter/opacity/scale, and button transitions include scale. Unused accordion keyframes are removed.                                                     |
| Icon strokes                    | The listed regular-text contexts use 1.5px Lucide strokes. Existing semibold contexts retain 2px.                                                                                                                         |
| Image edges and hover restraint | All five image locations have neutral white 10% outlines at 1px. Knowledge-link arrows stay still while their existing color/underline feedback remains.                                                                  |
