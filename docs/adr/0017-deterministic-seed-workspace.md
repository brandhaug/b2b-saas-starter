# Deterministic seed workspace

Superseded by [ADR 0052](./0052-first-slice-booking-storage.md). The Booking Product uses a typed, clock-anchored Seed Booking Scenario centered on a Merchant rather than the generic Starter's Seed Workspace.

The starter includes deterministic seed data for local development, tests, and showcase screenshots. The seed workspace should include members, starter modules, adoption readiness states, integration surfaces, implementation reports, notifications, and catalog refresh history so the reference app is useful immediately while making seeded content easy to identify and replace.
