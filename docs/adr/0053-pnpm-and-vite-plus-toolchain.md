# pnpm and Vite+ toolchain (Bun removed)

The starter manages dependencies with pnpm (pinned in `packageManager`, catalog and overrides in `pnpm-workspace.yaml`) and runs its toolchain through the [Vite+ CLI](https://viteplus.dev) (`vp`): Vite, Rolldown, Vitest, Oxlint, Oxfmt, and Vite Task come from one pinned `vite-plus` package instead of separate catalog pins. Node is the only runtime (>= 24, vp-managed locally; Bun is removed entirely, including `bun-types`, `@effect/platform-bun`, and `bunx --bun` script forms), and Vite Task replaced Turborepo as the task runner.

This replaces the starter's earlier Bun-only package management. That decision's argument — lockfile and documentation simplicity around one tool — still holds; pnpm + vp keeps the same one-path simplicity while reusing the VoidZero stack the repo already ran à la carte (Vite 8, Vitest 4, oxlint/oxfmt): `vp migrate` unified their versions, `vp run` carries the per-package script cache Turbo provided, and the `staged` block in the root `vite.config.ts` replaced lint-staged with a format-only pre-commit hook. Lint and typecheck are a documented validation requirement (`pnpm run check`) rather than a commit gate — see [0018 — Scripts over CLI](./0018-scripts-over-cli.md) for the command surface this preserves.
