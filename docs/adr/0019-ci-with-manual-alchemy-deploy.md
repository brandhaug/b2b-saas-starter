# CI with Alchemy deploy on merge

The starter includes GitHub Actions for CI. CI runs typecheck, lint, format check, unit tests behind a coverage ratchet, a dependency audit gate, and build, then migrates and seeds the local D1 before the Playwright e2e job. The deploy job runs the documented `pnpm run deploy` Alchemy command after `ci` and `e2e` pass. It triggers on every push to `master` — so a merged PR deploys automatically — and remains available on manual `workflow_dispatch` for deploying a specific ref on demand. Teams still configure Cloudflare accounts, secrets, and project identifiers (the `production` environment secrets) before the first deploy; without them the deploy job fails loudly rather than deploying partial configuration.
