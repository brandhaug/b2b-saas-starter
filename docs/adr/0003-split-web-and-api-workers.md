# Split web and API workers

The starter uses both a TanStack Start web worker and a separate Cloudflare API worker. The web worker owns pages, server functions, and Better Auth routes, while the API worker owns the public REST API and MCP server; both depend on shared capability, auth, database, and Effect HTTP contract packages so behavior is not duplicated. The MCP surface is live: `GET /mcp` serves a discovery document derived from the same descriptor table the server registers, and `POST /mcp` answers JSON-RPC (streamable HTTP, stateless — no Durable Object per ADR 0009) through the official TypeScript SDK. Tool execution dispatches through the same capability seam as REST.
