The Platform API is a server-to-server surface for one Merchant. It exposes
read-only Merchant, Service, Provider, and Appointment resources under `/v1`, plus
API-token and Webhook-endpoint configuration. It is not a customer booking channel
or the data layer for first-party applications.

Clients send a one-time-disclosed bearer token. Only its hash persists; each token
belongs to one Merchant and carries explicit data-read or integration scopes.
Cross-Merchant and missing-resource lookups share the same non-disclosing response.

Pagination cursors are signed, endpoint/filter-bound, expire after 24 hours, and
contain no Customer Details. Generated OpenAPI is served at `/openapi.json` and the
reference UI at `/reference`.
