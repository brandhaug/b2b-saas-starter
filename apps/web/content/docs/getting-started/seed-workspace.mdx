`buildSeedBookingScenario(anchorTime)` is the sole authored Booking fixture. It
contains one verified Owner and Merchant, two Providers, active/inactive Services,
eligibility, schedule rules, a Published page, and fixed-clock Appointments and
Confirmation metadata.

`bun run db:seed` projects the graph into the same persisted Wrangler D1 state used
by local Workers. Rerunning it replaces only `mer_seed_booking_studio`; unrelated
Merchant data remains intact. Capability adapters, end-to-end setup, and screenshot
workflows derive from this graph rather than maintaining parallel fixtures.
