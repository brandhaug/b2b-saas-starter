Requires Bun 1.3.3 or later. A Cloudflare account is needed only for deployment.

```bash
bun install
cp .env.example .env
bun run db:migrate:local
bun run db:seed
bun run dev
```

Turbo starts the Public Site (3071), Merchant App (3072), Booking App development
server (3073), Platform API (8787), and Background Worker (8788). Customer traffic
uses the Public Site; the Booking App direct origin is development-only.

The canonical seeded Merchant is available at `/mara-booking-studio`. Merchant App
credentials are `merchant@booking.local` / `merchant-booking-password`. The seed
is fixed-clock and repeatable against persisted local D1.
