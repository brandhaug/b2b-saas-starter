# Cabinet Grotesk

Cabinet Grotesk by Indian Type Foundry, distributed through [Fontshare](https://www.fontshare.com/fonts/cabinet-grotesk). Downloaded 14 September 2026 from the official Fontshare stylesheet for the variable family. The unmodified WOFF2 is self-hosted for public display headings. Geist remains the application and body face.

The included `cabinet-grotesk-license.txt` is the ITF Free Font License distributed with the font. Preserve it with the font file.
